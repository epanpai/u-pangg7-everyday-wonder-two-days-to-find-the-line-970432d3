## The entry

> The spider rebuilt its web across my doorway overnight, so this morning I ducked under it like a guest in someone else's house.

127 characters, one sentence: a spider web across an ordinary doorway, and the human who meets it in the morning ducks underneath like a polite guest in someone else's house. The reversal is the surprise — the spider is the householder, the human the visitor — and it lands in a single read, grounded in something real and specific: a doorway, overnight, a duck under a thread.

## How it works

`main.ts` (Node 22, stdlib only) writes the fixed sentence to `/output/entry.txt` — 127 characters, inside the 1–200 character gate. Deterministic, no network, no secrets, no randomness.

Run locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
